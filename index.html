Artemis

Artificial but Intelligent

  • Artemis v1.23.1
  • Artemis v1.0.0
Artemis is an AI assistant that can control some aspects of your computer, while also being a helpful AI chatbot.
Here you can download the latest public build of Artemis, and also visit the Github page, to view to source code.

1. To use Artemis, choose a version from the dropdown box, and select it to download it.

2. After your version is downloaded, double click the "Artemis.zip" and wait for the file to be extracted.

3. Once the folder has been extracted, open it, and double click on the app icon with the Artemis logo.

4. Now that Artemis has been downloaded, you're now good to use Artemis!
